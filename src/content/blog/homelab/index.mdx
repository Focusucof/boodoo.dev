## Introduction

This guide walks through how I built my homelab. The goal of this setup is to have a flexible environment where I can experiment with infrastructure, networking, security tools, and self-hosted services that run stably and efficiently.

The lab is designed around three principles:

- Full control of infrastructure
- Isolated environments for experimentation
- Security and privacy
